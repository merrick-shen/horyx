# 坦克动荡（tank）

本地双人同屏坦克对战：随机迷宫中双车对决，虚拟摇杆驾驶 + 开火钮射击，
含击毁结算、计分与自动开新一局的完整回合流程。
基于 Flame 游戏引擎 + Soloud 音频引擎（flutter_soloud）；
局域网联机对局尚未接入（建房满员后停留等待页「即将开始」过渡态）。

## 文件结构

| 目录/文件 | 职责 |
| --- | --- |
| `models/` | 纯数据与算法：`TankPlayer`（玩家/染色/驾驶输入）、`TankMaze`（迷宫生成与墙查询） |
| `pages/` | `tank_page` 设置页（本地/局域网模式选择）、`tank_battle_page` 横屏对局页（比分 UI、输入下发、横屏沉浸） |
| `widgets/` | UI 组件：四向摇杆（油门）、开火按钮、比分视图（含得分烟雾覆盖层）、模式面板 |
| `game/` | Flame 游戏核心：`tank_maze_game`（战场：迷宫渲染/回合流程/开火/计分）、`tank`（坦克实体与碰撞）、`bullet`（子弹实体与反弹）、`tank_audio`（音效） |
| `game/effects/` | 粒子特效：`particle_emitter`（瞬发粒子发射器）、`tank_explosion_effect`（坦克爆炸）、`bullet_expire_effect`（子弹消散） |

## 回合运行流程

1. **开局**：生成随机迷宫（递归回溯完美迷宫，默认 10×7，全图连通无环路）；红方出生左下角朝右、绿方出生右上角朝左（点对称）；
2. **对局中**：命中判定常开——任一存活子弹命中任一存活坦克即击毁（**自己反弹的子弹打中自己也算**）；
3. **击毁 → 结算期 3 秒**：战场不冻结——残弹继续飞行/反弹/**命中**（**双杀可能发生**），存活方仍可驾驶开火；受害者隐身、锁定其输入、不再参与碰撞与命中；
4. **结算期到点 → 计分**：存活方得一分；结算期内双方都阵亡（残弹双杀）则**本轮双方都不得分**（一轮最多计一次分）；
5. **计分后 → 冻结期 1 秒**：战场整体定格（坦克与子弹全部停在原地，不再推进、不到期、不命中）；
6. **开新一局**：重新生成迷宫、坦克回出生点复活、清空场上子弹，**比分保留**（无限连玩，暂无"先到 N 胜"规则）。

## 粒子特效

三个特效均为**纯渲染叠加**：不参与碰撞、不读写游戏逻辑状态；全部使用 `assets/tank/` 白模纹理
（圆斑烟雾 `explosion_smoke.png`、三角碎片 `tank_shard.png`、爆闪软圆 `explosion_flash.png`），
经 `tintFilter` 按目标色做通道缩放染色（黑=烟雾、白=爆闪、玩家色=碎片）。

**发射器 `ParticleEmitter`**（Cocos2d 重力模式粒子语义）：挂载即瞬发全部粒子，每帧积分
速度 + 重力 + 径向加速度，尺寸/透明度按寿命插值；长度参数统一乘 `sizeScale`（pt → 战场像素，
按素材坦克体长 48pt 对齐 `_cell`，保证任何屏幕下与坦克比例一致）。支持：撞墙停驻
（`hitTest` 由战场注入）、粒子自旋、慢淡出曲线（`fadeExp`，前段保持可见后段消散）、
碎片拖尾（飞行中按概率沿途留烟）。全部粒子过期后自移除。

### 坦克被击毁爆炸（`TankExplosionEffect`，总时长上限 3 秒）

触发：`_onTankDestroyed` 在爆点（受害者上帧屏幕坐标）叠加，配 `TankAudio.explosion` 音效；
受害者隐身由既有逻辑负责，特效只负责视觉表现。四层同时触发：

| 层 | 运作流程 |
| --- | --- |
| 三角碎片（染受害者色，12 粒） | 全向炸开（130±80 pt/s），每粒大小/角度/距离各异、寿命内自旋 540°；负径向加速度（-260）向外减速，**减速到零或撞墙即停驻**（不会空中回弹），停驻后原地慢淡出（寿命 1.8±0.2s，`fadeExp=2.5`） |
| 拖尾小烟（黑，随碎片生成） | 碎片飞行中按 12 粒/秒·粒 概率沿途留烟，停驻后降为 30% 概率续烟避免断档；寿命 1.0s 缓慢膨胀淡出——最后一批尾烟在碎片死亡瞬间生成，**消散到 3.0s 上限，比碎片消失得慢** |
| 中心大烟（黑，3 粒） | 爆点快速膨胀闪现（0.45±0.15s）即散，不驻留 |
| 爆闪（白，12 粒） | 全向爆出快速消散（0.5±0.2s），营造起爆瞬间强光 |

四层（含拖尾）全部消散后 `TankExplosionEffect` 自移除；开新一局时 `_clearEffects` 兜底清理。

### 子弹消散（`BulletExpireEffect`，总时长 0.6 秒）

触发：两个子弹消失点——`_pruneExpiredBullets`（9 秒射程极限到期）与 `_checkBulletHits`
（命中坦克），在子弹上帧屏幕坐标叠加。单层：5 粒黑烟在消失点**全向原地散开**
（20±10 pt/s）、缓慢膨胀（12→16）淡出（寿命 0.5±0.1s），消散后自移除。

### 得分烟雾（`ScoreSmokeEffect`，widget 层，总时长 1 秒）

覆盖在比分数字上（战场之外的 Flutter 组件），链路：战场计分 → `onScored` 回调 →
对局页自增 `_redSmokeTick`/`_greenSmokeTick` → `didUpdateWidget` 检测到 tick 自增立即爆烟。
`TankScoreView` 通过 `numberOverlay` 参数把覆盖层与数字同尺寸叠放（Stack +
`IgnorePointer`，不拦截手势）。单层 10 粒：

- **底部生成**：粒子下缘贴数字底边、横向聚在数字中心（±0.3 数字宽散开 + ±0.1 漂移，
  成团又散开；横向参数按数字宽归一化，**两位数时烟宽自动等比加宽**）；
- **上飘覆盖数字**：1 秒匀速上飘 0.7 个数字高（按数字高归一化），线性淡出；
- **硬约束**：绘制时 `clipRect` 裁剪到数字自身矩形，烟雾任何时刻不越数字边界；
- Ticker 驱动 `setState` 重绘，全部消散后自动停表避免空转。

## 注意事项（重要坑点）

1. **坐标双体系**：坦克/子弹的权威状态（`logicalPos`、朝向）存于**迷宫坐标系**（单位=格，原点迷宫左上角），与画布尺寸无关；Flame 组件的 `position`/`scale` 只是每帧由战场同步的渲染映射。画布 resize（进对局横屏旋转、前后台切换）只重建迷宫外观并重新换算渲染坐标，**不会重置坦克状态**；新迷宫只在新一局生成。
2. **渲染层级**：坦克/子弹 `priority = 1`，迷宫组件默认 0。画布 resize 会把迷宫组件删除后重新加到渲染队列末尾，若去掉 priority，重建后的不透明底板会把坦克盖住（"坦克消失" bug 的根源）。
3. **定格期冻结必须先于 `super.update`**：`update` 第一行的 `super.update` 会推进全部子组件，冻结判断若放在其后，定格的 1 秒内坦克与子弹仍会移动（"定格期子弹还在飞" bug 的根源）。
4. **遍历与清场必须分离**：命中判定遍历子弹分组时（map 与列表均用快照），绝不能同时清空这些集合；命中结算（清场/冻结/计分）在扫描结束后统一进行。在遍历中修改集合会抛 concurrent modification 异常打断游戏循环（"击中后计分正常但全场卡死"崩溃的根源，Windows 端会直接断连）。
5. **SAT 投影半径公式**：必须用矩形自身轴与测试轴的点积和（`_projRadius`）。不能套轴对齐盒公式 `half.x*|ax| + half.y*|ay|`——旋转矩形朝上下时会把长轴算成薄边，导致上下方向穿墙（该 bug 曾出现：左右炮管顶墙正常、上下穿透）。
6. **炮塔缩放系数勿回退**：圆顶直径 = 车宽 × 0.75 为原版截图逐像素实测值；曾因整文件重写两次回退成 1.0 导致炮管显大，构造函数注释中已有警示。
7. **击毁坦克的处理**：隐身（渲染缩放归零）、输入冻结、不参与碰撞与命中、不能开火；位置可被对方与子弹自由穿过；新一局复位复活。
8. **计分规则**：一轮最多计一次分；双杀不得分；自伤（自己的反弹弹）命中 = 对方得分。
9. **素材约束**：`assets/tank/` 全部为白模素材（提取自原版 APK，版权属原开发商，仅限个人本地项目），运行时按玩家色做通道缩放染色——更换素材必须保持"白色主体 + 黑描边 + 透明底"才能正确染色；炮塔素材（Bullet0 裁边后 125×74）圆顶中心位于 (36.5, 37)，安装时圆顶中心必须对齐车体中心。

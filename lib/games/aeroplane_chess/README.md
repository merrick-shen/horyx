# 飞行棋（aeroplane_chess）

四人经典飞行棋（支持 2～4 人）：掷骰起飞、同色跳跃、加油站飞越与撞子对抗，
率先送四架飞机抵达终点获胜。棋盘为八角形盘（外环 52 格四色循环 + 中央
X 形四色跑道 + 四角停机坪），以实物图逐格核对定稿。支持本地 2～4 人同屏
轮流与局域网 2～4 人联机（房主权威 + 全量状态快照广播）。棋盘与骰子均为
CustomPainter/自绘组件，无图片素材、无音效。

## 文件结构

| 目录/文件 | 职责 |
| --- | --- |
| `models/` | 纯数据与拓扑：`aeroplane_game_state`（对局状态存档模型：棋子四区域位置、行动方、连 6 计数、胜负；含默认颜色分配与摘要文案）、`aeroplane_board`（棋盘拓扑常量表：外环 52 格颜色、各色起飞格/跑道入口/加油站航线、环格↔坐标换算）、`aeroplane_colors`（四色展示常量：棋盘格/棋子加深变体色/骰面点色） |
| `services/` | `aeroplane_engine`（规则引擎：纯静态逻辑，走法枚举与连锁迁移单函数收敛，本地与联机同源判定）、`aeroplane_storage`（多存档仓库 `ArchiveStorage` 子类）、`aeroplane_online_controller`（联机对局控制器：房主掷骰/裁决广播、客户端请求上报、快照幂等应用）、`aeroplane_net_models`（联机协议编解码：纯数据模型，全字段类型校验） |
| `pages/` | `aeroplane_page` 本地对局页（设置/恢复/存档退出/回合流转与动画编排）、`aeroplane_online_page` 联机对局页（复用本地棋盘/棋子/回合组件与走子动画器，骰点与状态随房主广播同步） |
| `widgets/` | `aeroplane_board_view`（棋盘：`CustomPainter` 格子层 + 棋子层 Stack 定位，叠子横向错开、动画棋子帧坐标覆盖渲染）、`aeroplane_move_animation`（走子动画器：路径逐段滑行 + 被撞飞回，本地与联机共用；含路径构建纯函数）、`aeroplane_dice`（图形化点阵骰面：点阵布局常量表驱动）、`aeroplane_plane`（棋子：四色加深变体、可动高亮/选中描边、完成勾标识）、`aeroplane_game_view`（本地对局视图组装）、`aeroplane_setup_view`（人数设置与恢复入口、本地/局域网模式选择） |

## 规则与回合流程

1. **起飞**：掷出 2/4/6 才可起飞（已确认变体，经典为仅 6），先落到基地旁
   **准备区**（不踏上跑道、不参与环道撞子）；准备区棋子下次掷任意点数即踏上
   跑道（起飞格为第 1 步，掷 N 落第 N 格）。
2. **行进**：按骰点沿外环前进，进入己方跑道后奔向终点；终点即**己方跑道末格**，
   必须**恰好**步数抵达，超出部分从跑道尽头逐格回退。
3. **同色跳跃**：落在与己方颜色相同的外环格，自动顺跳到下一个同色格（间隔恒 4，
   起飞格与入口格除外）；回退落点若为己色格同样触发。
4. **加油站飞越**：恰好落在己方加油站起点格（己色格）时触发即沿虚线航线飞越至
   对面落点（UI 不提供不飞越的选择）；飞越路径穿越敌方跑道时其上敌机被撞回；
   落点可再接一次跳跃。全程上限「一次飞越 + 一次跳跃」。
5. **撞子**：落点有敌方棋子（含叠子整体）送回其停机坪；己色格对己方安全、对他色
   不保护（安全格豁免；飞越航线穿越的跑道格不豁免）。
6. **连 6 惩罚**：连续第 3 个 6，最后移动的己方棋子返回停机坪（已抵达终点者除外）
   并换人；掷出非 6 即清零计数。
7. **再掷奖励**：掷 6、撞子、跳跃、飞越后奖励再掷一次（迁移后行动方不变）；
   同一次迁移多触发只奖励一次。
8. **胜负**：4 架飞机全部抵达终点（跑道末格）即获胜，对局立即结束；完成的飞机
   飞回基地机位以勾标识展示进度。
9. **无可动棋子**：掷骰后无合法走法自动跳过回合换人（含三 6 惩罚但无可罚棋子
   的情形，UI 统一提示「无可动棋子，跳过回合」）。

## 联机对战

**架构：房主权威 + 全量状态快照重同步**（与棋类「提交—增量广播」不同，飞行棋
回合内含掷骰随机与连锁迁移，采用快照协议，详见 `aeroplane_online_controller.dart`
顶部注释）：

- **房主端**：骰子只在房主侧生成——客户端发掷骰请求，房主掷骰广播结果；三 6 惩罚
  或无可动棋子时房主立即迁移并广播状态；走子提交经房主用与本地同源的引擎全量
  校验（客户端不可信，本地预检过的规则房主全部重做）后迁移广播。
- **客户端**：上报掷骰请求与走子提交，状态以快照广播为准；快照按房主权威递增
  序号**幂等应用**，防御消息重复与乱序；矛盾快照（座位不在玩家之列）走数据异常
  终局。

**协议消息**（NDJSON TCP；编解码在 `aeroplane_net_models.dart`，载荷全字段类型校验，
非法一律丢弃）：

| 消息 | 方向 | 载荷 |
| --- | --- | --- |
| `aeroplaneRollRequest` | 客户端 → 房主 | 无（仅当前行动方且未掷骰的请求被受理，其余静默忽略） |
| `aeroplaneRollResult` | 房主 → 全员 | `value`（骰点 1..6）+ `seq`（权威递增序号） |
| `aeroplaneMoveSubmit` | 客户端 → 房主 | `planeId`（棋子编号）+ `fly`（是否飞越） |
| `aeroplaneMoveResult` | 房主 → 提交者 | `ok` + 拒绝时 `reason`（`notYourTurn`/`noDice`/`invalidMove`，null-aware 省略） |
| `aeroplaneState` | 房主 → 全员 | `seq` + 全量状态快照（`AeroplaneGameState.toJson`） |
| `gameOver` | 房主广播 | `reason: 'peerLeft'`（任一玩家离开的无胜负终局） |

**座位与颜色**：座位顺序即玩家列表顺序（房主 1 号位），颜色按人数默认分配
（2 人对角 绿+蓝、3 人连续 绿红蓝、4 人全色），行动顺序 绿→红→蓝→黄、绿方先掷。
联机对局**不落本地存档**；**不提供认输与悔棋**（与本地一致），中途退出/断线即
无胜负终局（无对局重连）。

**联机动画还原（不改协议）**：快照不携带走法语义，客户端由迁移前后状态经同源
引擎**重放推断**实际走法与骰点（逐骰点枚举合法走法、比对主棋子终点），据此构建
与本地一致的逐格/飞越/撞子飞回动画路径；三 6 惩罚按「行动方棋子回停机坪」识别
为直线飞回。重放未命中（理论不发生）退化为直线滑行。

## 注意事项（重要坑点）

1. **引擎单函数收敛连锁**：回退、跳跃、飞越、撞子、再掷判定全部在
   `applyMove`/`_resolve` 内一次完成，UI 只消费迁移结果，禁止在 UI 层补规则；
   连锁上限「一次飞越 + 一次跳跃」防循环。
2. **三 6 惩罚须先判定再枚举**：连续第 3 个 6 时 `legalMoves` 直接抛错（防止把
   惩罚回合当普通走子），所有枚举/迁移调用点必须先过 `isThirdSixPenalty`。
3. **坐标双体系**：拓扑表以棋盘中心为原点、格为单位的归一化坐标表达格子与棋子
   位置，渲染层按画布尺寸线性映射；换算函数（`ringAnchor` 等）为纯函数，引擎与
   渲染共用同一映射，勿在绘制层另算坐标。
4. **完成与被撞的区分**：完成的飞机 zone 为 `goal`（绘制在基地机位 + 勾标识），
   被撞回的飞机 zone 为 `hangar`——两者坐标都是机位中心，但语义与动画处理不同
   （联机客户端按 zone 区分撞子/完成/惩罚）。
5. **快照序号幂等**：掷骰结果与状态快照共用房主侧递增序号，客户端小于等于已
   应用序号的广播一律丢弃；序号跨越两类消息连续递增，勿按消息类型分序号空间。
6. **联机骰面翻动信号**：以控制器 `pendingDice` 由空转非空识别新骰点广播（迁移
   消费后复位），骰点值相同的新一掷同样触发；快照应用会清空 `pendingDice`，
   翻动定格取启动时捕获的值。
7. **跳过回合不可区分**：无可动跳过与「三 6 惩罚但无可罚棋子」的快照终态完全
   一致（协议不携带掷骰语义），UI 统一提示「无可动棋子，跳过回合」；有罚棋子的
   惩罚才有专属动画与文案。
8. **动画期间显示迁移前状态**：本地页与联机页都在动画期间保持旧状态、移动棋子
   由动画器帧坐标覆盖呈现，动画结束才切换为新状态；动画器本地与联机共用，勿在
   某一侧另写实现。
9. **起飞落点不触发连锁**：停机坪起飞一律落准备区（`ready`），不撞子、不跳跃；
   准备区出发的逐格路径以起飞格为第 1 步（步数基线取 -1 使序列含起飞格）。
